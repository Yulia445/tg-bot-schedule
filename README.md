# 🤖 Schedule Support Bot (Support Bro)
Schedule Support Bot — це інтелектуальний Telegram-асистент для керування розкладом занять. Проєкт базується на поєднанні сучасних методів обробки природної мови (NLP) та надійної архітектури зберігання даних. Бот не просто зберігає текст, а розуміє контекст запиту користувача, автоматично ідентифікуючи предмети, викладачів та часові слоти.

# 🌟 Ключові особливості
Інтелектуальний парсинг запитів: Використання моделі Llama 3.3 (via Groq API) дозволяє боту обробляти запити у довільній формі (наприклад: "додай інгліш у вівторок першою парою").

Динамічна база знань: Бот автоматично асоціює скорочені назви дисциплін з повними іменами викладачів та аудиторіями.

Автоматизація форматування: Впроваджено алгоритми на основі регулярних виразів (Regex) для очищення вводу від артефактів та підтримки чистоти бази даних.

Статус занять: Можливість скасування ("smart cancel") та відновлення ("uncancel") пар з візуальною індикацією в загальному розкладі.

Логічне сортування: Автоматичне впорядкування занять за днями тижня та часом проведення.

# 🛠 Технологічний стек
Мова програмування: Python 3.10+

Framework: Aiogram 3.x (Asynchronous Telegram Bot API)

LLM Engine: Groq Cloud (Llama-3.3-70b-versatile)

База даних: SQLite3

Environment: Dotenv (безпечне зберігання API-ключів)

# 🔧 Встановлення та налаштування
Клонування репозиторію:

Bash
git clone https://github.com/yourusername/schedule-support-bot.git
cd schedule-support-bot
Встановлення залежностей:

Bash
pip install aiogram python-dotenv groq
Конфігурація середовища:
Створіть файл .env у кореневій папці проєкту:

Фрагмент коду
TELEGRAM_TOKEN=your_bot_token_here
GROQ_API_KEYS=your_groq_api_key_here
ADMIN_ID=your_telegram_id
Ініціалізація бази даних та запуск:

Bash
python main.py
