# 📚 Telegram-бот "Support Bro" — Інтелектуальний помічник студента
🚀 Elevator Pitch

Support Bro — це інноваційний асистент для керування навчальним розкладом, який поєднує зручність Telegram-інтерфейсу та потужність великих мовних моделей (Llama 3.3). Бот дозволяє студентам взаємодіяти з базою даних розкладу за допомогою природної мови, автоматизуючи рутинні процеси додавання, скасування та сортування занять.

# 🎯 Цільова аудиторія

Проєкт розроблений для студентів та старост академічних груп, які потребують оперативного доступу до розкладу, можливості миттєво вносити зміни (наприклад, через раптове скасування пари) та зручного візуального відображення навчального плану на тиждень.

# 🛠 Технічна архітектура
Проєкт побудований на принципі модульності:

UI-шар (Telegram): Побудований на базі бібліотеки Aiogram 3.x.

AI-модуль: Інтеграція з Groq API для парсингу довільного тексту користувача у структуровані SQL-команди.

Data-шар: Реляційна база даних SQLite3 для надійного зберігання та швидкого пошуку інформації.

# ⚙️ Покрокова інструкція із запуску
1. Підготовка середовища

Переконайтеся, що у вас встановлено Python 3.10 або новішої версії.

2. Встановлення залежностей

Відкрийте термінал у папці проєкту та виконайте команду:

Bash
pip install aiogram python-dotenv groq
3. Налаштування API-ключів

Створіть у кореневій папці файл під назвою .env та додайте наступні параметри:

Фрагмент коду
TELEGRAM_TOKEN=ваш_токен_від_BotFather
GROQ_API_KEYS=ваш_ключ_від_Groq_Cloud
ADMIN_ID=ваш_числовий_ID_телеграм_аккаунта
4. Запуск проєкту

Запустіть головний файл програми:

Bash
python main.py
# 📋 Основний функціонал (Приклади використання)
Додавання: "Додай англійську мову на понеділок другою парою, 541 ауд."

Скасування: "Скасуй 3 пару в середу" (Бот автоматично додасть позначку ❌).

Відновлення: "Поверни четверту пару в п'ятницю".

Перегляд: Натисніть кнопку 📚 Розклад для отримання структурованого списку занять, відсортованого за днями тижня.

📂 Структура проєкту
main.py — логіка взаємодії з Telegram та обробка відповідей нейромережі.

database.py — робота з БД SQLite, форматування тексту розкладу та очищення даних.

university.db — файл бази даних (створюється автоматично при першому запуску).

.env — конфігураційний файл для ключів (необхідно створити власноруч).
